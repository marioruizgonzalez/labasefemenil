1. Comparación de Goleadoras por Temporada
Muestra las máximas goleadoras por temporada y torneo.

sql
Copy code
SELECT 
    temporada,
    torneo,
    jugador,
    club,
    SUM(goles) AS total_goles
FROM 
    lbf_goleo
GROUP BY 
    temporada, torneo, jugador, club
ORDER BY 
    temporada ASC, total_goles DESC;

3. Eficiencia de Goleo
Muestra la relación entre minutos jugados y goles anotados por jugadora.

sql
Copy code
SELECT 
    jugador,
    club,
    SUM(goles) AS total_goles,
    SUM(mj) AS total_minutos,
    ROUND((SUM(mj) / NULLIF(SUM(goles), 0)), 2) AS minutos_por_gol
FROM 
    lbf_goleo
GROUP BY 
    jugador, club
ORDER BY 
    minutos_por_gol ASC;

6. Menos Participación de Menores por Club
Muestra los minutos acumulados por menores alineadas en cada club.

sql
Copy code
SELECT 
    temporada,
    torneo,
    club,
    SUM(minutos_acumulados_2) AS minutos_totales_menores,
    SUM(minutos_al_reglamento) AS minutos_por_reglamento
FROM 
    lbf_participacion_menores
GROUP BY 
    temporada, torneo, club
ORDER BY 
    temporada ASC, minutos_totales_menores DESC;

1. Clubes con Más Tarjetas por Minuto Jugado
sql
Copy code
SELECT 
    club,
    SUM(total_tarjetas) AS total_tarjetas,
    SUM(promedio_x_minutos) AS minutos_totales,
    (SUM(total_tarjetas) / SUM(promedio_x_minutos)) AS tarjetas_por_minuto
FROM 
    lbf_tarjetas_club
GROUP BY 
    club
ORDER BY 
    tarjetas_por_minuto DESC;

Copy code

3. Jugadoras con Mayor Ineficiencia Goleadora
sql
Copy code
SELECT 
    jugador,
    club,
    SUM(mj) AS minutos_totales,
    SUM(goles) AS goles_totales,
    (SUM(mj) / NULLIF(SUM(goles), 0)) AS minutos_por_gol
FROM 
    lbf_goleo
GROUP BY 
    jugador, club
HAVING 
    SUM(goles) > 0
ORDER BY 
    minutos_por_gol DESC
LIMIT 10; -- Muestra las 10 jugadoras menos eficientes

6. Clubes con Mayor Diferencia de Goles Negativa
sql
Copy code
SELECT 
    club,
    SUM(gf - gc) AS diferencia_de_goles
FROM 
    lbf_historical_stats
GROUP BY 
    club
HAVING 
    SUM(gf - gc) < 0
ORDER BY 
    diferencia_de_goles ASC
LIMIT 10; -- Muestra los 10 clubes con mayor diferencia negativa
